# Page templates for WordPress

Этот каталог содержит готовые шаблоны страниц, добавленные как файлы темы: page-contacts.php, page-arendatoram.php, page-documents.php, page-our-activities.php.

Как использовать:
1. Поместите папку `wp-theme` в корень вашей темы (или переместите файлы в корень активной темы).
2. В админке WordPress создайте новые страницы и в блоке "Атрибуты страницы" выберите соответствующий шаблон (например, "Контакты").
3. Отредактируйте содержимое страницы (если нужно) в стандартном редакторе; шаблон будет подставлять либо содержимое страницы, либо предоставленный фолбэк.

Дальнейшие шаги, которые могу выполнить:
- Автоматически создать страницы в базе WP (INSERT в wp_posts). Требует доступа к базе.
- Импортировать реальные тексты и документы из архива tomskagroinvest.zip.
- Подключить стили в functions.php через wp_enqueue_style.
